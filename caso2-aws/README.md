# Caso 2 — Avaliação de Arquiteturas de Nuvem (AWS)

**Síntese:** *"A Hybrid DEA-Gaussian AHP Approach for Evaluating AWS Cloud Architectures"* (Research and Innovation Forum, 2026 — no prelo).

## O desafio (contexto)

Avaliação complexa de arquiteturas de nuvem (AWS) devido à multiplicidade de critérios e opções, e a necessidade de um método robusto para comparar e selecionar a arquitetura mais eficiente.

## A aplicação (metodologia)

Aplicação da abordagem híbrida combinando DEA (Análise Envoltória de Dados) e AHP Gaussiano. O método avalia e ranqueia diferentes arquiteturas de nuvem AWS com base em eficiência relativa.

## Resultados (impacto)

Geração de um ranking claro e objetivo das arquiteturas de nuvem avaliadas, identificação das arquiteturas mais eficientes (apoiando a tomada de decisão estratégica) e um framework para otimização contínua e seleção baseada em dados.

## Conteúdo desta pasta

- `DEA_AHPGS_AWS_CLOUD.ipynb` — implementação do método híbrido DEA-GS (o utilizado na dissertação).
- `método_DEA_PURO_case_AWS.ipynb` — notebook de comparação com o DEA clássico (CRS/VRS).
- `dados/DADOS testes AWS.csv` — dados de entrada do estudo.
- `dados/Comparação AWS DEAGS-CRS-VRS.xlsx` — comparação de resultados entre DEA-GS e DEA clássico.
